# Curso de Python aplicado a ciberseguridad

Repositorio con los ejercicios y proyectos que he ido desarrollando mientras
aprendo Python orientado a la seguridad y a la programación de aplicaciones.
Todo el código es material de estudio, pensado para ejecutarse en **entornos
de laboratorio controlados y propios** (máquinas virtuales aisladas).

## Qué he practicado aquí

- **Programación orientada a objetos (POO):** clases, herencia y organización
  del código en módulos.
- **Concurrencia con hilos (threading):** ejecución de tareas en paralelo.
- **Programación de red con sockets:** comunicación cliente-servidor.
- **Interfaces gráficas con Tkinter:** varias aplicaciones de escritorio.
- **Análisis de red con Scapy:** construcción y lectura de paquetes en un
  laboratorio propio.

## Tecnologías

Python 3 · Tkinter · sockets · threading · Scapy

## Aviso

Este repositorio es material de formación. El código de las partes de red y
seguridad está pensado **únicamente** para pruebas en equipos y redes propios,
dentro de un laboratorio aislado. No debe usarse sobre sistemas de terceros.
